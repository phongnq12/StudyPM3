# Danh mục component (mẫu — thay bằng thư viện thật)
| Component | Dùng khi | Biến thể | Ghi chú |
| --- | --- | --- | --- |
| Button | Hành động | primary, secondary, danger, link | Mỗi màn hình tối đa 1 primary |
| Input text | Nhập chữ ngắn | thường, có icon, chỉ đọc | |
| Textarea | Nhập chữ dài | | Có đếm ký tự nếu có giới hạn |
| Select | Chọn 1 trong danh sách | thường, có tìm kiếm | Trên 10 lựa chọn dùng có tìm kiếm |
| Date picker | Chọn ngày | ngày, khoảng ngày | |
| Table | Danh sách bản ghi | có chọn dòng, có hành động dòng | Luôn có phân trang |
| Modal | Xác nhận, form ngắn | xác nhận, form | |
| Toast | Thông báo kết quả | thành công, lỗi, cảnh báo | Thời gian tự ẩn theo SCR-000; thông báo lỗi không tự ẩn (WCAG 2.2 tiêu chí 2.2.1) |
| Badge | Trạng thái | theo màu trạng thái | Map trạng thái ST-xxx sang màu |
| Alert / Callout | Thông báo trong trang | thông tin, cảnh báo, lỗi, thành công | Nội dung chỉ lấy từ SCR mục 6 (SCR-000 mục 5 cho thông báo chung); không có → khối giữ chỗ (SKILL.md mục "Nội dung chữ trên giao diện") |
